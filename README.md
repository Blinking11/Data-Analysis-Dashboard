# HR Analytics: Employee Attrition & Workforce Performance Dashboard
## Project Objective
The objective of this HR Analytics project is to analyze workforce demographics, compensation, job satisfaction, and promotion trends to identify the root causes of employee turnover. The dashboard provides data-driven insights to help HR leadership optimize retention strategies, balance departmental workloads, and benchmark compensation

## Question KPIs
- Which department experiences the highest turnover?
- How does employee compensation correlate with attrition risk?
- How does promotion stagnancy impact employee retention over time?
- What is the average employee retention/tenure across different functional units?
- How do different job roles score on employee well-being?
- What is the compensation distribution for specialized roles by demographic attributes?
